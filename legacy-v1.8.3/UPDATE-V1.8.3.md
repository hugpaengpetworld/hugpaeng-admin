# อัปเดตระบบเป็น V1.8.3

รุ่นนี้แก้ไข 3 จุดโดยไม่เพิ่มคอลัมน์และไม่เปลี่ยนหัวตารางใน Google Sheets

1. หมายเลขโทรศัพท์ที่ Google Sheets เก็บเป็นตัวเลขและทำเลข `0` ด้านหน้าหาย
   จะแสดงด้วยรหัสประเทศไทย `+66` เช่น `925424461` จะแสดงเป็น `+66925424461`
   โดยไม่แก้ค่าต้นฉบับในชีต
2. หากวันออกตามแผนยังมาไม่ถึง ระบบจะถามยืนยันการเช็กเอาต์ก่อนกำหนด และฝั่ง
   Apps Script จะตรวจยืนยันซ้ำเพื่อป้องกันการกดโดยไม่ตั้งใจ แต่ยังอนุญาตให้เช็กเอาต์
   ก่อนกำหนดได้เมื่อพนักงานยืนยัน
3. เปลี่ยนหัวคอลัมน์ `Option` เป็น `ใบเสร็จ`

## ไฟล์ Apps Script ที่ต้องวางทับ

- `00_Config.gs`
- `01_BusinessRules.gs`
- `05_AdminService.gs`
- `13_ReceiptService.gs`
- `AdminClient.html`

จากนั้น Deploy Apps Script เป็น **New version** และใช้ URL ที่ลงท้ายด้วย `/exec`

## ไฟล์ Cloudflare/GitHub ที่ต้องอัปเดต

หลังรัน `npm run build:cloudflare` ให้อัปโหลดหรือวางทับ:

- `cloudflare-web/public/index.html` → `public/index.html`
- `cloudflare-web/public/admin/index.html` → `public/admin/index.html`

แล้ว Commit และรอ Cloudflare Deploy สำเร็จ

## หมายเหตุเรื่องรายการเดิม

รายการที่อยู่ในหมวด “ดำเนินการเสร็จแล้ว” และมีวันออกในอนาคต หมายความว่า
สถานะใน Google Sheets ถูกเปลี่ยนเป็น `CHECKED_OUT` ไปแล้ว ระบบรุ่นนี้จะไม่ย้อนสถานะ
ข้อมูลเดิมอัตโนมัติ เพราะอาจเป็นการเช็กเอาต์ก่อนกำหนดจริง หากเป็นการกดผิดให้ระบุ
รหัสการจองเพื่อซ่อมสถานะเป็นรายรายการอย่างปลอดภัย
