# ระบบจองที่พักสัตว์ชั่วคราว v1.8.3

สำหรับ **คลินิกบ้านหมอปอยรักษาสัตว์** พัฒนาด้วย Google Sheets + Google Apps Script
เพื่อใช้ระหว่างรอระบบ SaaS หลัก โดยไม่พึ่ง Supabase

รุ่น 1.8.3 แสดงหมายเลขโทรศัพท์ด้วยรหัสประเทศไทย `+66` เพิ่มการยืนยันสองชั้น
เมื่อเช็กเอาต์ก่อนวันออกตามแผน และเปลี่ยนหัวคอลัมน์ `Option` เป็น `ใบเสร็จ`
โดยไม่แก้ข้อมูลโทรศัพท์เดิมและไม่เพิ่มคอลัมน์ใน Google Sheets

รุ่น 1.8 เพิ่มการกำหนดวันหยุดทำหมัน โดยแสดงวันหยุดเป็นสีชมพู คิวครบ 4 ตัว
เป็นสีแดง และคิวเกิน 4 ตัวเป็นสีม่วง เจ้าของหรือหมอสามารถรับจองในวันหยุด
แบบยกเว้นได้หลังยืนยัน ส่วนพนักงานทั่วไปไม่มีสิทธิ์ยกเว้นวันหยุด

รุ่น 1.7 ใช้หน้าเว็บ Cloudflare ที่ `bmpbooking.hug-paeng.com` โดยให้ Cloudflare
Worker ส่งคำขอไป Apps Script API และให้ Google Sheets เป็นฐานข้อมูลเดิม กุญแจเชื่อมต่อ
เก็บเป็น Cloudflare Secret และไม่ถูกส่งไปยังเบราว์เซอร์ของลูกค้า

## สิ่งที่ระบบทำได้

- หน้าเว็บลูกค้าภาษาไทย รองรับโทรศัพท์และคอมพิวเตอร์
- Responsive สำหรับ PC, iPad และ Smartphone พร้อมเมนูหลังบ้านแบบเลื่อนออกบนจอสัมผัส
- ตั้งชื่อสถานบริการภาษาไทย/อังกฤษและอัปโหลดโลโก้ส่วนกลางเพื่อใช้ทุกหน้าของระบบ
- ไอคอน SVG แบบรวมศูนย์สำหรับเมนูหลังบ้าน คมชัดทุกขนาดจอและใช้สีขาวบนแถบเมนูสีเขียวเข้ม
- ค้นหาจำนวนห้องว่างโดยไม่เปิดเผยรหัสห้อง
- วันที่ทุกหน้าแสดงเป็น `วัน-เดือน-ปี ค.ศ.` (`DD-MM-YYYY`) และเก็บ/ส่งข้อมูลภายในเป็น ISO ค.ศ. (`YYYY-MM-DD`)
- อ่านข้อมูลวันที่เดิมได้ทั้งรูปแบบใช้ `/`, `-`, พ.ศ., ค.ศ. และค่า Date/เวลาเดิมจาก Google Sheets
- ส่งคำขอแล้ว **กันความจุทันที** ด้วยสถานะ `PENDING_APPROVAL` หรือ “รออนุมัติห้อง”
- หลังบ้านแยกต่างหาก พร้อมชื่อผู้ใช้/รหัสผ่าน
- สิทธิ์ 3 ระดับ: เจ้าของ หมอ และพนักงาน
- พนักงานอนุมัติ/ปฏิเสธ กำหนดห้อง ตรวจมัดจำ และใช้หน้าเช็กอิน–เช็กเอาต์ที่แสดงรายการค้างดำเนินการทุกวัน
- หน้าเช็กอิน–เช็กเอาต์แยกแมว/สุนัข และแสดงรหัสการจอง เจ้าของ ชื่อสัตว์ ห้องพัก วันเข้า และวันออก
- สถานะ `CHECKED_IN` ยึดห้องไว้เสมอจนกดเช็กเอาต์จริง แม้เลยวันออกตามแผนแล้ว
- เช็กอินบันทึกมัดจำจริงและหมายเหตุอาหาร/การชำระ ส่วนเช็กเอาต์สรุปค่าอาหาร ค่ายา น้ำเกลือ ตรวจเลือด หรือรายการอื่น
- บันทึกอาหาร ขนม หรือค่าใช้จ่ายเพิ่มเติม และคำนวณยอดสุทธิ
- ขอเลื่อนวันผ่านเว็บด้วยรหัสการจอง + เบอร์โทร
- มัดจำ 500 บาทเฉพาะรายการ LINE
- หมดเวลามัดจำ 1 ชั่วโมงแล้วคืนห้องอัตโนมัติ พร้อมส่ง LINE
- แนบสมุดวัคซีนและสลิปแบบไม่บังคับ/ตามขั้นตอน
- ฝากเช้า–รับเย็น และกรงเจ้าของ เป็นเมนูพนักงานเท่านั้น
- กันรหัสห้องพักอัตโนมัติเมื่อรับคำขอ และให้พนักงานเปลี่ยนจากดรอปดาวน์ตามชนิดสัตว์ได้
- การ์ดห้องแสดงสีว่าง รออนุมัติ อนุมัติ/เข้าพัก และปิดใช้งานอย่างชัดเจน
- เลือกดูสถานะห้องของวันถัดไปได้ และกดการ์ดเพื่อจองหรือเปิดรายละเอียดรายการ
- การ์ดที่มีการจองแสดงไอคอน SVG แมว/สุนัขและป้ายชื่อสัตว์ สูงสุด 2 ตัว
- รหัสจองค้างคืนรูปแบบ `BMP-DDMMBBBB-ROOM-NN` เช่น `BMP-01082569-CAT07-01`
- เมนูห้องพักแมวและห้องพักสุนัขแยกจากกัน พร้อมเลือกดูตามวันที่
- รับจองหลังบ้านหลายห้องในครั้งเดียว โดยกรอกข้อมูลเจ้าของครั้งเดียวและแยกสัตว์ตามห้อง
- เมนูทำหมันสำหรับหลังบ้าน พร้อมปฏิทิน: ต่ำกว่า 4 คิวสีเขียว, ครบ 4 สีแดง และเกิน 4 สีม่วง
- ตั้งวันหยุดทำหมันจากข้างช่องเลือกเดือน วันหยุดเป็นสีชมพู และอนุญาตให้เจ้าของ/หมอยืนยันรับจองแบบยกเว้นได้
- พนักงานหรือหมอเพิ่มคิวทำหมันเกิน 4 ตัวได้ และกดชื่อสัตว์บนปฏิทินเพื่อดูรายละเอียด อายุ และวัคซีน
- นัดทำหมันเลือกชนิดสัตว์จาก สุนัข/แมว/อื่น ๆ และเลือกเพศผู้/เมียจากดรอปดาวน์
- มี Audit Log, session expiry และการล็อกบัญชีชั่วคราวเมื่อเดารหัสผิดหลายครั้ง

## ขั้นตอนติดตั้งแบบสั้น

1. เปิด Google Sheet แม่แบบ
2. ไปที่ **ส่วนขยาย → Apps Script**
3. นำไฟล์ในโฟลเดอร์ `src` เข้าโครงการ Apps Script
4. ตั้งเขตเวลาเป็น `Asia/Bangkok`
5. รันฟังก์ชัน `setupSystem()` หนึ่งครั้ง และอนุญาตสิทธิ์
6. บันทึกรหัสผ่านชั่วคราวของผู้ใช้ `owner`
7. Deploy เป็น **Web app**
   - Execute as: ผู้ติดตั้ง/เจ้าของสคริปต์
   - Who has access: Anyone
8. หากใช้หน้า Apps Script โดยตรง เปิด URL หลักสำหรับลูกค้า และเติม `?page=admin` สำหรับหลังบ้าน
9. หากใช้โดเมน `bmpbooking.hug-paeng.com` ให้ทำตาม [docs/INSTALL-CLOUDFLARE.md](docs/INSTALL-CLOUDFLARE.md)

อ่านรายละเอียดที่ [docs/INSTALL.md](docs/INSTALL.md)

## ความปลอดภัย

- ไม่เก็บรหัสผ่านแบบข้อความธรรมดา
- Token ของ LINE เก็บใน Apps Script Script Properties
- ตรวจสิทธิ์ซ้ำทุกคำสั่งที่ฝั่งเซิร์ฟเวอร์
- จำกัดไฟล์แนบ 5 MB และรับ JPG, PNG, WEBP, PDF; โลโก้รับ JPG, PNG, WEBP ไม่เกิน 1 MB
- ไฟล์แนบอยู่ในโฟลเดอร์ Drive แบบ Private
- คืนส่วนต่างได้เฉพาะบทบาทเจ้าของ และต้องยืนยันบัญชีต้นทาง
- ไม่ควรแชร์ Google Sheet หรือโฟลเดอร์ไฟล์แนบให้บุคคลทั่วไป
- Apps Script API ตรวจ shared gateway key และรับเฉพาะคำสั่งใน allow-list
- Cloudflare Worker ตรวจ allow-list ซ้ำ และไม่บันทึกเนื้อหาคำขอหรือข้อมูลส่วนตัวลง log

## ข้อจำกัดก่อนใช้งานจริง

- ต้องรัน `setupSystem()` และ Deploy ในบัญชี Google ของคลินิก
- ระบบเดิมรุ่น 1.0 ให้วางไฟล์รุ่นใหม่แล้วรัน `upgradeSystemV1_1()` หนึ่งครั้งก่อน Deploy รุ่นใหม่
- การอัปเดตหน้าจอ Responsive รุ่น 1.2 ไม่ต้องรันฟังก์ชันอัปเกรดฐานข้อมูล
- การอัปเดตชื่อและโลโก้รุ่น 1.3 ไม่ต้องรันฟังก์ชันอัปเกรดฐานข้อมูล
- การอัปเดตชุดไอคอน SVG รุ่น 1.3.1 ไม่ต้องรันฟังก์ชันอัปเกรดฐานข้อมูล
- การอัปเดตปฏิทินห้อง ไอคอนสัตว์ และรหัสจองรุ่น 1.4 ไม่ต้องรันฟังก์ชันอัปเกรดฐานข้อมูล รหัสเดิมยังใช้ค้นหาได้ตามเดิม
- การอัปเดตรุ่น 1.5 ให้วางไฟล์ใหม่ทั้งหมดแล้วรัน `upgradeSystemV1_5()` หนึ่งครั้งก่อน Deploy เพื่อเพิ่มคอลัมน์กลุ่มการจอง หมายเหตุเช็กอิน อายุ และวัคซีน โดยไม่ลบข้อมูลเดิม
- การอัปเดตรุ่น 1.6 จาก 1.5 ไม่เปลี่ยนหัวคอลัมน์ จึงไม่ต้องรัน migration เพิ่ม ให้วาง `00_Config.gs` และเพิ่ม `10_ApiService.gs` แล้วตั้งค่า Cloudflare Gateway ตามคู่มือ
- การอัปเดตรุ่น 1.6.1 ปรับวันที่ทั้งระบบเป็น `DD-MM-YYYY` และรองรับข้อมูลวันที่เดิมโดยอัตโนมัติ ไม่ต้องแก้ข้อมูลใน Google Sheets หรือรัน migration
- การอัปเดตรุ่น 1.7 ให้วางไฟล์ใหม่ทั้งหมด แล้วรัน `upgradeSystemV1_7()` หนึ่งครั้งก่อน Deploy ฟังก์ชันจะเปลี่ยนรหัสห้อง `C01–C11` เป็น `CAT01–CAT11`, `D01–D07` เป็น `DOG01–DOG07`, ปรับ `assigned_room_id` และซ่อม `current_booking_id` ของรายการ `CHECKED_IN` โดยไม่เปลี่ยนรหัสการจองเดิมและไม่เพิ่ม/สลับหัวคอลัมน์
- การอัปเดตรุ่น 1.8.1 ให้วางทับไฟล์เดิมทั้งหมด สร้างไฟล์ใหม่ `13_ReceiptService.gs` แล้วรัน `upgradeSystemV1_8()` หนึ่งครั้งก่อน Deploy เพื่อเพิ่มชีต `วันหยุดทำหมัน`, `ใบเสร็จ` และ `รายการใบเสร็จ` โดยไม่ลบข้อมูลเดิม ดูรายละเอียดใน `UPDATE-V1.8.1.md`
- การอัปเดตรุ่น 1.8.2 ไม่เพิ่มหัวคอลัมน์ใน Google Sheets และไม่ต้องรันฟังก์ชันอัปเกรดซ้ำ ให้วางไฟล์ใหม่แล้ว Deploy **Apps Script เป็น New version** และ Deploy Cloudflare ใหม่ทั้งคู่ ดูรายละเอียดใน `UPDATE-V1.8.2.md`
- การอัปเดตรุ่น 1.8.3 ไม่เพิ่มหัวคอลัมน์ใน Google Sheets ปรับการแสดงเบอร์โทรเป็น `+66`, เพิ่มการยืนยันเช็กเอาต์ก่อนวันออกตามแผน และเปลี่ยนหัวคอลัมน์เป็น `ใบเสร็จ` ดูรายละเอียดใน `UPDATE-V1.8.3.md`
