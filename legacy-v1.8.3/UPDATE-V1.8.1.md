# คู่มืออัปเดต BMP Booking เป็น V1.8.1

รุ่นนี้เพิ่มระบบออกและพิมพ์ใบเสร็จหลังเช็กเอาต์ โดยยังคงข้อมูลการจองเดิมทั้งหมด

## สิ่งที่เพิ่มในรุ่นนี้

- ออกเลขใบเสร็จอัตโนมัติรูปแบบ `BMP-RCP-YYYYMMDD-0001`
- เก็บสำเนาข้อมูลใบเสร็จและรายการค่าใช้จ่ายแยกจากข้อมูลการจอง
- เลือกวิธีชำระเงินและใส่หมายเหตุในขั้นตอนเช็กเอาต์
- พิมพ์ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์ รองรับกระดาษความร้อน 80 มม.
- หากการสร้างใบเสร็จขัดข้อง การเช็กเอาต์และการคืนห้องยังคงสำเร็จ และสามารถสั่งพิมพ์ใหม่ภายหลังได้

## ขั้นตอนอัปเดต

1. สำรอง Google Sheets และโปรเจกต์ Apps Script ปัจจุบันก่อนเริ่ม
2. วางทับไฟล์เดิมทั้งหมดจากโฟลเดอร์ `src`
3. สร้างไฟล์ใหม่ชื่อ `13_ReceiptService.gs` ใน Apps Script แล้ววางโค้ดจาก `src/13_ReceiptService.gs`
4. เลือกฟังก์ชัน `upgradeSystemV1_8` แล้วกด Run หนึ่งครั้ง
5. อนุญาตสิทธิ์ Google Drive หาก Google แสดงหน้าขอสิทธิ์
6. ตรวจว่า Google Sheets มีชีต `วันหยุดทำหมัน`, `ใบเสร็จ` และ `รายการใบเสร็จ`
7. Deploy Apps Script เป็นเวอร์ชันใหม่ โดยใช้ URL ที่ลงท้ายด้วย `/exec`
8. วางทับไฟล์ใน `cloudflare-web` และ Deploy Cloudflare Worker ใหม่
9. ทดสอบเช็กเอาต์หนึ่งรายการ เลือกวิธีชำระเงิน และกดพิมพ์ใบเสร็จ

## หมายเหตุสำคัญ

- ใช้ชื่อฟังก์ชัน `upgradeSystemV1_8()` ตามเดิม แม้รุ่นแพ็กเกจจะเป็น V1.8.1
- ฟังก์ชันอัปเกรดเป็นแบบ idempotent จึงไม่ลบข้อมูลเดิมและเรียกซ้ำได้อย่างปลอดภัย
- ใบเสร็จเป็นข้อมูล snapshot เมื่อออกแล้ว เพื่อไม่ให้การแก้รายการจองภายหลังเปลี่ยนเอกสารเดิม
- ปุ่มพิมพ์จะเปิด Print dialog ของเครื่อง ผู้ใช้เลือกเครื่องพิมพ์ใบเสร็จที่ติดตั้งใน Windows หรือ macOS ได้โดยตรง
- ไม่ควรวาง `GAS_GATEWAY_KEY` หรือข้อมูลลับอื่นลงใน GitHub ให้เก็บเป็น Cloudflare Secret เท่านั้น
