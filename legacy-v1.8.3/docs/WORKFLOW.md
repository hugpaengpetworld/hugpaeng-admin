# สถานะและการกันห้อง

## การจองทั่วไป

1. ลูกค้าหรือพนักงานส่งคำขอ
2. ระบบล็อกการเขียนชั่วคราว ตรวจจำนวนห้องว่างอีกครั้ง
3. ถ้ามีห้อง ระบบบันทึก `PENDING_APPROVAL`
4. สถานะนี้ถูกนับว่าใช้ความจุทันที
5. พนักงานเลือก:
   - อนุมัติรายการเว็บไซต์/Facebook/โทรศัพท์/Walk-in → `CONFIRMED`
   - อนุมัติ LINE → `APPROVED_AWAITING_DEPOSIT`
   - ปฏิเสธ → `REJECTED` และคืนความจุ

สถานะที่ใช้ความจุ:

- `PENDING_APPROVAL`
- `APPROVED_AWAITING_DEPOSIT`
- `CONFIRMED`
- `CHECKED_IN`

สถานะที่ไม่ใช้ความจุ:

- `REJECTED`
- `EXPIRED_PAYMENT`
- `CANCELLED_NO_REFUND`
- `CHECKED_OUT`
- `NO_SHOW`

## การมัดจำ LINE

1. อนุมัติคำขอ LINE
2. ระบบกำหนด deadline อีก 60 นาที
3. ลูกค้าแนบสลิป
4. พนักงานตรวจยอดและกดตรวจรับ
5. ระบบเปลี่ยนเป็น `CONFIRMED`
6. ถ้าหมดเวลาและยังไม่ตรวจรับ ระบบเปลี่ยนเป็น `EXPIRED_PAYMENT`
7. ห้องถูกคืน และระบบส่ง LINE แจ้งอัตโนมัติ

## การเลื่อนวัน

- ลูกค้ายืนยันด้วยรหัสการจอง + เบอร์โทร
- ตรวจสิทธิ์: ยังไม่เคยเลื่อน และวันเข้าปัจจุบันห่างอย่างน้อย 3 วัน
- ระบบตรวจและกันความจุของช่วงวันใหม่ระหว่างรอพนักงาน
- วันเดิมยังคงอยู่จนกว่าพนักงานอนุมัติ
- เมื่ออนุมัติ ระบบเปลี่ยนวัน คำนวณราคาใหม่ ล้างห้องที่กำหนด และเพิ่มจำนวนครั้งเป็น 1

## การชำระและคืนส่วนต่าง

ยอดรวม = ค่าที่พัก + ค่าอาหาร/ขนม/ค่าใช้จ่ายเพิ่มเติม

- ยอดรวมมากกว่ามัดจำ → ลูกค้าชำระเพิ่ม
- ยอดรวมน้อยกว่ามัดจำ → คืนเฉพาะส่วนต่าง
- การคืนส่วนต่างทำได้เฉพาะ OWNER
- ต้องยืนยันว่าชื่อและเลขบัญชีตรงกับบัญชีต้นทาง
- ระบบบันทึกเลขบัญชีแบบปิดบัง เหลือท้าย 4 หลัก
