- หน้าเข้าสู่ระบบใช้ Tab ตามลำดับ อีเมล → รหัสผ่าน → เข้าสู่ระบบ → ลืมรหัสผ่าน และมี focus indicator ที่มองเห็นได้.
- ผู้ใช้ที่ยังไม่เข้าสู่ระบบถูกส่งกลับ `/admin/login?reason=session` จาก `/admin`, `/admin/bookings`, `/admin/rooms/cats`, `/admin/rooms/dogs`, `/admin/sterilization`, `/admin/finance`, `/admin/users`, และ `/admin/settings`.

## Checklist การใช้งานจริง

### 1. เข้าสู่ระบบและ HOME หลังบ้าน

- [ ] OWNER เข้าสู่ระบบและออกจากระบบได้.
- [ ] HOME แสดงชื่อ/โลโก้ที่ตั้งค่าไว้และเมนูตามสิทธิ์ โดยไม่มีข้อความหรือองค์ประกอบล้นจอ.
- [ ] เมนูมือถือเปิดและปิดได้; ปุ่มย้อนกลับและการหมุนจอไม่ทำให้หน้าเสียรูป.
- [ ] ผู้ใช้ที่ไม่มีสิทธิ์ไม่เห็นข้อมูลหรือทำรายการที่เกินสิทธิ์ได้.

### 2. ทะเบียนลูกค้าและสัตว์เลี้ยง

- [ ] ค้นลูกค้าเดิมด้วยเบอร์โทร ชื่อเจ้าของ ชื่อสัตว์ หรือ HN ได้.
- [ ] เลือกสัตว์เดิมหลายตัวและเพิ่มสัตว์ใหม่ให้เจ้าของเดิมได้โดยไม่สร้างเจ้าของซ้ำ.
- [ ] สัตว์ใหม่ได้รับ HN แยกต่อสัตว์หนึ่งตัว.

### 3. ฝากเลี้ยงและห้องพัก

- [ ] สร้างคำขอจองทั่วไปและเปิดรายละเอียดจากรายการจองได้.
- [ ] การ์ดห้องแสดง cursor รูปมือและคลิกหนึ่งครั้งเปิด action; ห้องว่างเปิดฟอร์มพร้อมวันที่ ชนิดสัตว์ และห้องที่เลือก.
- [ ] ฟอร์มบนการ์ดค้นด้วยเบอร์โทร ชื่อเจ้าของ ชื่อสัตว์ หรือ HN และเลือกสัตว์เดิมหลายตัวของเจ้าของคนเดียวได้โดยไม่สร้างทะเบียนซ้ำ.
- [ ] สร้างหรือเช็กอินจากการ์ดห้องแมวและห้องสุนัขได้; ห้องและชนิดสัตว์ตรงกัน.
- [ ] ห้องรออนุมัติ/ยืนยัน/กำลังพัก/ทำความสะอาดแสดงข้อความและ badge เข้าใจได้โดยไม่อาศัยสีอย่างเดียว.
- [ ] เปิดชื่อสัตว์เพื่อดูข้อมูลเจ้าของ/เบอร์โทร/สัตว์โดยไม่เปิด action ผิดรายการ.
- [ ] เช็กเอาต์จากการ์ดห้องได้; ห้องเปลี่ยนเป็น `รอทำความสะอาด` และไม่ว่างทันที.

### 4. ปฏิทินทำหมัน

- [ ] ปฏิทินเดือนอ่านง่ายและเลื่อนเดือน/เลือกวันได้บนทุกอุปกรณ์.
- [ ] การ์ดวันและชื่อสัตว์แสดง cursor รูปมือ; คลิกหนึ่งครั้งที่วันเพื่อสร้างรายการ และคลิกชื่อสัตว์เพื่อดูรายละเอียดได้.
- [ ] ฟอร์มสร้างนัดค้นด้วยเบอร์โทร ชื่อเจ้าของ ชื่อสัตว์ หรือ HN และเลือกสัตว์เดิมหนึ่งตัวได้โดยไม่สร้างทะเบียนซ้ำ.
- [ ] วันหยุด เต็ม และเกินคิวแสดงข้อความชัดเจน.

### 5. การเงิน, Dynamic PromptPay และใบเสร็จ

- [ ] ค่าใช้จ่ายเพิ่มเติมเพิ่มได้หลายแถว และ `อื่น ๆ` บังคับรายละเอียด.
- [ ] Dynamic PromptPay แสดงยอดตรงกับยอดสุทธิที่ต้องรับ; การแก้ค่าใช้จ่ายทำให้ quote เดิมใช้ต่อไม่ได้.
- [ ] การยืนยันเงินเข้าและเช็กเอาต์สร้างใบเสร็จเพียงหนึ่งใบต่อกลุ่ม และหักมัดจำ 500 บาทครั้งเดียว.
- [ ] ใบเสร็จแสดงที่อยู่/โทรศัพท์ และไม่แสดงข้อมูลภาษีเมื่อไม่ได้เปิดตั้งค่า.
- [ ] Browser print preview ใช้กระดาษ 80 มม. ข้อความและยอดเงินไม่ถูกตัด และพิมพ์จากเครื่องจริงได้.

### 6. Keyboard และ accessibility

- [ ] ใช้ Tab/Shift+Tab เข้าถึงเมนู การ์ด dropdown ปุ่ม และลิงก์ใน critical flow ได้.
- [ ] Enter/Space เปิด action และ Escape/ปุ่มปิดปิด dialog ได้โดยไม่ส่งฟอร์มผิดรายการ.
- [ ] ปิด dialog แล้ว focus กลับไปยังปุ่มหรือการ์ดที่เปิด dialog.
- [ ] Error, success, conflict, empty, unauthorized และ loading state อ่านเข้าใจได้และไม่แสดง raw enum/error.
