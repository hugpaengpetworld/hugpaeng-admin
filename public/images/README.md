# Images

เก็บเฉพาะภาพสาธารณะที่เป็นส่วนหนึ่งของเว็บไซต์ในโฟลเดอร์นี้

- `branding/` — โลโก้และภาพประจำคลินิก
- `website/` — ภาพหน้าเว็บไซต์สำหรับลูกค้า
- `admin/` — ภาพประกอบระบบหลังบ้าน
- `services/` — ภาพบริการฝากเลี้ยงและทำหมัน
- `placeholders/` — ภาพสำรองเมื่อยังไม่มีภาพจริง

ห้ามเก็บภาพลูกค้า สัตว์เลี้ยง สลิป เอกสารทางการแพทย์ หรือข้อมูลส่วนตัวใน `public/` ให้ใช้ Supabase Storage แบบ private แทน
